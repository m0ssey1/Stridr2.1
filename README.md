# Stridr

Personal running coach for high school and university athletes (ages 13-25): onboarding, 90-day plan,
log, reviews, race results. Single-file static app (`index.html`); data is stored in the browser
(localStorage). No nutrition advice. Not medical advice.

## Publish on GitHub Pages
1. Create a new public repository on github.com (for example `stridr`).
2. Upload every file in this folder (Add file > Upload files).
3. Settings > Pages > Source: Deploy from a branch > `main` / root > Save.
4. After about a minute the site is at `https://YOUR-USERNAME.github.io/stridr/`.

AI coach and account sync are not included in this static version.
